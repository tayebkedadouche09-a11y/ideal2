## 1. Synthèse

Le dépôt est une base **V1 + V2 substantielle** d’un seul produit Company OS, pas trois applications. La structure monorepo (domain, i18n, API Fastify, web React/MUI, migrations PostgreSQL) est cohérente avec `IDEAIL_MASTER_PRODUCT_SPEC.md`.

**Le produit n’est pas production-ready** : pas de vérification live Supabase/API/hosting, offline V3 incomplet jusqu’à cette itération, packaging mobile absent, tests d’intégration minimaux.

## 4. Sécurité

- Permissions **serveur** présentes (`requireScope`, isolation, audit).
- CORS allowlist sur `WEB_ORIGIN`.
- Secrets uniquement via env (`.env.example` sans secrets réels).
- Paiements append-only + `payment_reversal`.
- Portail client ne doit pas atteindre l’ERP interne (routes séparées + RBAC).
- À surveiller en continu : toute nouvelle route doit filtrer `company_id` **et** scope d’enregistrement.
